# Security Policy

## Reporting a vulnerability
Please don't report security vulnerabilities in public issues, pull requests or discussions.
Use [private vulnerability reporting](https://github.com/ShisatoYano/AutonomousVehicleControlBeginnersGuide/security/advisories/new) instead.
I will reply as soon as possible, and publish an advisory after the fix.

## Scope
This project is learning material. The code is for learning, research and prototyping, not for controlling real vehicles.
Reports about the code in this repository, its GitHub Actions workflows and, once released, its PyPI package are welcome.
