# Autonomous Vehicle Control Beginners Guide

Learn autonomous driving by building it: Python simulations and an open textbook where the system grows one stage at a time.

This web book is built from the documents in the [GitHub repository](https://github.com/ShisatoYano/AutonomousVehicleControlBeginnersGuide). It is a work in progress: the chapters below are the existing design documents, and they are being reorganized into a book that follows the learning path (see the [documentation roadmap](https://github.com/ShisatoYano/AutonomousVehicleControlBeginnersGuide/issues/165)). Comments and ideas are welcome in the [Book](https://github.com/ShisatoYano/AutonomousVehicleControlBeginnersGuide/discussions/categories/book) category of Discussions.
